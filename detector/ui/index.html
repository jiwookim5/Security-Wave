점검한 주소

누리집에 숨은 불법광고를 찾습니다

점검할 누리집 주소를 넣고 [탐지 시작]을 누르십시오. 그 주소에서 이어지는 페이지·게시글·댓글을 차례로 살펴봅니다.

점검 설정 기본값 그대로 두어도 됩니다

이 수만큼 페이지를 살펴보면 멈춥니다. 보통 1000이면 충분하고, 게시글이 아주 많은 누리집은 늘리십시오. 25분이 넘으면 그때까지의 결과로 마칩니다.

실제 기관 누리집을 점검할 때 켜십시오. 페이지 사이에 0.7초씩 쉬고, 누리집의 robots.txt 가 막아 둔 주소는 건너뜁니다. 짧은 시간에 요청이 몰려 보안 관제에서 공격으로 오인되거나 서버에 부담을 주는 일을 막습니다. 300페이지면 3~4분쯤 더 걸립니다.

게시글에 붙은 PDF·HWP·HWPX 파일 안의 글자도 검사합니다. 파일을 열거나 실행하지는 않습니다.

누리집 검색창이 광고 문구를 그대로 되비춰 구글 검색 결과에 광고가 뜨는 데 악용될 수 있는지 봅니다. 검색창마다 무해한 글자로 한 번만 검색해 봅니다.

같은 기관의 다른 주소(예: 게시판이 있는 bbs.기관.go.kr, 기관.go.kr:8080)로 이어지는 링크도 따라가 점검합니다. 끄면 입력한 주소의 누리집만 봅니다(www 유무는 같은 누리집으로 봅니다). 다른 기관 누리집은 켜도 점검하지 않습니다.

패밀리 사이트·배너처럼 다른 누리집으로 나가는 링크가 도박·성인 광고 사이트로 바뀌지 않았는지 봅니다. 옛 행사 누리집의 도메인이 만료되어 광고 업자에게 넘어간 경우를 찾습니다. 바깥 도메인마다 첫 화면 글자만 한 번 받아 보며, 브라우저로 열지 않으므로 스크립트가 실행되지 않습니다. 공공기관(go.kr 등) 누리집은 조회하지 않습니다. 인터넷이 막힌 PC 에서는 결과가 나오지 않습니다.

게시글·배너 그림을 받아 Windows 에 내장된 글자 인식으로 읽고, 광고 문구를 그림으로 만들어 올린 경우를 찾습니다. 그림을 받고 읽는 시간이 더 듭니다(같은 그림은 한 번만). 그림은 이 PC 안에서만 읽고 밖으로 보내지 않습니다. 한국어 글자 인식이 없는 PC 에서는 건너뜁니다. 첨부한 그림 파일과 스캔한 PDF 는 이 설정과 관계없이 첨부파일 검사에서 읽습니다.

검색엔진 로봇에게만 광고를 보여주도록 조작된 페이지를 찾습니다. 같은 주소를 한 번 더 열어 보므로 시간이 더 걸립니다.

색인 목록 (선택)

구글 Search Console 에서 내려받은 '색인된 페이지' 목록(CSV)을 넣으면, 구글에 이미 올라간 주소에 광고가 보이는지 하나씩 확인합니다. 없으면 넣지 않아도 됩니다.

🚀 빠른 시작

1️⃣ 탐지 시작

점검할 누리집 주소를 입력하고 "탐지 시작" 버튼을 클릭합니다. 그 누리집의 모든 페이지가 자동으로 검사됩니다.

예) example.gov.kr 입력 후 탐지 시작 → 자동 검사 시작

2️⃣ 결과 확인

검사가 끝나면 탐지된 불법광고 목록이 나타납니다. 각 광고마다 "어떻게 지울 것인지" 설명을 볼 수 있습니다.

위치 • 탐지 기법 • 삭제 방법을 한눈에 확인

3️⃣ 조치하고 확인

누리집 관리자 페이지에서 광고를 삭제한 후, "조치 확인" 버튼을 누르면 정말 삭제되었는지 다시 검사합니다.
