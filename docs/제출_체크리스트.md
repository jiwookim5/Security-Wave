## 유의사항

- 상용 AI API 미사용 → `.env` 요건 해당 없음. 사용설명서 첫 장에 미사용 명시함
- 색인 목록 점검은 담당자가 Search Console 에서 내려받은 파일을 쓰므로 검색 API 키·비용 없음
- 검색창 점검은 검색 기능마다 무해한 표식으로 GET 1회 조회함 (사용설명서 6장·기획서 '점검 대상 보호'에 명시)
- `result.json`·`result_extra.json` 은 구동 파일과 같은 폴더에 생성됨 (사용설명서 첫 장에 명시)
- 탐지에는 Windows 에 기본 설치된 Microsoft Edge 가 필요함 (사용설명서 2장에 명시)
- 코드 서명 없음. Smart App Control 차단·SmartScreen 경고 대처법은 사용설명서 7장에 있음
- 서류 규격 미준수·항목 누락·산출물 일부 누락 시 심사 제외
- 행정·공공기관 재직자는 소속 부서 업무와 무관한 경우에만 참여 가능
